Superstore Sales Data Analysis & Interactive Excel Dashboard

Project Overview

This project analyzes 9,994 transactional records from the Sample Superstore dataset covering 2014–2017. The objective is to evaluate sales performance, profitability, regional trends, and product performance using Microsoft Excel.

An interactive dashboard was developed to support exploratory data analysis and data-driven business decision-making.

Project Objectives

- Analyze historical sales and profitability across regions, categories, and years.
- Perform data cleaning, transformation, and quality validation.
- Develop an interactive dashboard using Excel PivotTables, PivotCharts, and slicers.
- Identify high-revenue and loss-making products.
- Translate analytical findings into actionable business recommendations.

Tools & Techniques

- Microsoft Excel: Data cleaning, transformation, and analysis
- Excel Formulas: IF, COUNTIF, COUNTIFS, SUMIFS, TRIM, and other functions
- PivotTables: Aggregation and performance analysis
- PivotCharts: Data visualization and trend analysis
- Slicers: Interactive filtering by Region and Year
- Dashboard Development: KPI cards and interactive visualizations

Key Business Insights

The following findings focus on the West region in 2016, using the dashboard's Region and Year filters.

- Sales Performance: The West region generated $187,480.18 in sales.
- Profitability: Total profit reached $24,051.61, representing a 12.83% profit margin.
- Category Performance: Furniture generated $73,819.64 in sales but only $2,653.93 in profit.
- Top Revenue Product: Okidata MB760 Printer generated $7,834.40 in sales.
- Loss-Making Product: Zebra GK420t Printer recorded a net loss of $938.28.

Data Analysis Methodology

1. Imported the Sample Superstore dataset into Excel.
2. Cleaned and validated transactional records.
3. Created calculated fields for business analysis.
4. Performed exploratory analysis using Excel formulas and PivotTables.
5. Developed interactive PivotCharts and KPI cards.
6. Implemented Region and Year slicers.
7. Identified business insights and developed recommendations.

Business Recommendations

- Review discounting strategies for low-profit and loss-making products.
- Investigate Furniture category profitability and associated costs.
- Monitor product-level performance to identify potential financial risks.
- Use interactive dashboard insights to support sales and profitability decisions.
